# Кнопка CV без постійної анімації

- **Task id:** cv-button-static
- **Services:** web (frontend)
- **Infra changes:** no
- **QA:** e2e (Playwright), глибина `smoke`

## 1. Goal
Оранжеві кнопки «Download CV» / «Завантажити CV» не мають постійно анімуватися, бо це відволікає відвідувача. Кнопка лишається оранжевою, а реагує лише на наведення.

## 2. Service changes

### web (frontend)
- **Місце:** клас `.primary` у [src/styles/ui.module.scss](../../src/styles/ui.module.scss). Його використовують лише дві кнопки CV: `cv-header` у хедері та `cv-hero` у hero.
- **Прибрати:** нескінченний відблиск — псевдоелемент `.primary::after` з анімацією `shine` (4.5s infinite) — разом з keyframes `shine`, якщо вони більше ніде не використовуються.
- **Не змінювати:**
  - фон `var(--accent2)` (оранжевий) в обох темах, колір тексту, тінь у спокої;
  - поточний hover: підйом `translateY(-2px)` і збільшена тінь;
  - картку CV у контактах (`cv-contact`) та інші анімації сторінки.
- **Required `data-testid`:** без змін (`cv-header`, `cv-hero`, `cv-contact`).

## 5. Acceptance criteria
1. **AC-1 — Без постійної анімації.** У спокої (без наведення) `cv-header` і `cv-hero` не мають жодної активної CSS-анімації ні на самому елементі, ні на `::before`/`::after`. Вигляд кнопки не змінюється з часом: два скриншоти з інтервалом 3 с ідентичні.
2. **AC-2 — Колір.** `cv-header` і `cv-hero` мають оранжевий фон (`--accent2`) в обох темах, як і раніше.
3. **AC-3 — Hover.** При наведенні кнопка піднімається на 2 px і тінь збільшується, як і раніше. Коли курсор іде з кнопки, вона повертається у спокійний стан.
4. **AC-4 — Без регресій.** Кнопки, як і раніше, ведуть на `/cv.pdf` з атрибутом `download`. Набір `e2e/portfolio-layout.spec.ts` проходить.

## 6. Test focus (for QA)
- **What changed for the user:** кнопки CV у хедері та hero більше не мерехтять.
- **What could break nearby:** hover-ефект кнопок, колір у світлій темі, кнопка «View work» (вона має клас `.btn`, але не `.primary`).
- **Not to re-test:** решта сторінки, окрім прогону наявного набору.
- **Risky cases:** reduced motion (анімацій і так немає), мобільна ширина 390 (кнопка в хедері показує «CV»).
